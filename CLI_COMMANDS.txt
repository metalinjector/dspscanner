DSP Scanner 2.9.9 — ПОЛНОЕ ОПИСАНИЕ КОМАНДНОЙ СТРОКИ
=========================================================

1. НАЗНАЧЕНИЕ
-------------
CLI-режим запускает сканирование без графического интерфейса. Он подходит для:

* Windows Server и файловых серверов;
* Планировщика заданий Windows;
* bat/cmd/PowerShell-скриптов;
* автоматического формирования отчётов;
* автоматической отправки отчётов по SMTP.

CLI не импортирует PySide6/Qt. Для сервера без GUI можно установить облегчённый
набор зависимостей:

    python -m pip install -r requirements_cli.txt

Полный набор, включающий GUI:

    python -m pip install -r requirements.txt


2. СПОСОБЫ ЗАПУСКА
------------------
Из папки программы:

    python main.py --cli [ПАРАМЕТРЫ]

Равнозначная форма:

    python main.py cli [ПАРАМЕТРЫ]

После сборки в EXE предполагается аналогичная форма:

    DSPScanner.exe --cli [ПАРАМЕТРЫ]

Обычный запуск без --cli открывает графический интерфейс:

    python main.py

Справка, сформированная самой программой:

    python main.py --cli --help

Версия:

    python main.py --cli --version


3. КОНФИГУРАЦИЯ JSON
--------------------
По умолчанию CLI загружает наиболее свежий файл:

    DSPScanner_Config\search_settings.json

Эта папка находится рядом с программой. Если она недоступна для записи,
программа может использовать резервную папку в профиле пользователя.

Явно указать конфигурацию:

    --config "D:\DSP\server_scan.json"

Полностью игнорировать автоматическую конфигурацию:

    --no-config

Любой параметр командной строки имеет приоритет над значением из JSON.
Если параметр в командной строке не указан, используется значение из JSON.

Переменная окружения для другой папки конфигурации:

    set DSP_SCANNER_CONFIG_DIR=D:\DSP\Config

После этого CLI и GUI будут искать автоматический JSON в указанной папке.


4. ПАРАМЕТРЫ ОБЛАСТИ ПОИСКА
---------------------------

--path PATH
    Корневая папка или отдельный файл. Ключ можно повторять.

    Пример:
        --path "D:\Documents" --path "E:\Archive"

    Если указан хотя бы один --path, список путей из JSON заменяется.

--types LIST
    Расширения через запятую или точку с запятой.
    Поддерживаются: docx, doc, txt, pdf.

    Пример:
        --types "docx,doc,pdf"

--max-size-mb NUMBER
    Максимальный размер файла в мегабайтах для чтения содержимого.
    Поиск по названию файла может выполняться и для более крупных файлов.

    Пример:
        --max-size-mb 100


5. КЛЮЧЕВЫЕ СЛОВА ДЛЯ СОДЕРЖИМОГО
---------------------------------

--content-term TEXT
    Один термин или словосочетание. Можно повторять.

    Пример:
        --content-term "пилот" --content-term "служебная записка"

--content-terms TEXT
    Несколько терминов в одной строке. Разделители: запятая, точка с запятой
    или перевод строки. Обычный пробел является частью словосочетания.

    Пример:
        --content-terms "пилот; беспилотный аппарат; договор"

--content-terms-file FILE
    UTF-8 или UTF-8 BOM текстовый файл со списком терминов.
    Размер файла ограничен 5 МБ.

    Пример:
        --content-terms-file "D:\DSP\content_words.txt"

Если задан хотя бы один из трёх ключей выше, список терминов для содержимого
из JSON полностью заменяется значениями командной строки.


6. КЛЮЧЕВЫЕ СЛОВА ДЛЯ НАЗВАНИЙ ФАЙЛОВ
--------------------------------------

--filename-term TEXT
    Один термин для поиска только в названии файла. Можно повторять.

--filename-terms TEXT
    Несколько терминов через запятую, точку с запятой или перевод строки.

--filename-terms-file FILE
    UTF-8 файл со списком терминов для названий.

Пример:

    --filename-term "пилот" --filename-term "отчёт"

При выключенном режиме целых слов термин "пилот" найдёт название,
содержащее "беспилотник". Это же правило действует для содержимого файлов.


7. ПРАВИЛА СОВПАДЕНИЯ
---------------------

--case-sensitive
    Учитывать регистр.

--no-case-sensitive
    Не учитывать регистр.

--whole-word
    Искать только целое слово. В этом режиме "пилот" НЕ совпадёт с
    "беспилотник".

--no-whole-word
    Разрешить совпадение по части слова. В этом режиме "пилот" совпадёт с
    "беспилотник".

--context NUMBER
    Число символов контекста вокруг найденного фрагмента.

    Пример:
        --context 50

--max-matches NUMBER
    Максимальное число совпадений одного термина в одном файле.

    Пример:
        --max-matches 100

Для парных флагов --option/--no-option отсутствие обоих ключей означает:
использовать значение из JSON.


8. ЧТЕНИЕ DOC И OCR
-------------------

--doc-method auto
    Автоматический метод: сначала быстрая эвристика, затем LibreOffice или
    MS Word только если эвристика не извлекла текст. Рекомендуется по умолчанию.

--doc-method libreoffice
    Использовать LibreOffice/soffice для legacy DOC.

--doc-method com
    Использовать MS Word COM. Доступно только на Windows при установленном Word.

--doc-method heuristic
    Быстрая эвристика без внешних программ на первом проходе.

--external-after-heuristic-failure
    После полного эвристического прохода повторно обработать ошибочные .doc
    доступными внешними программами.

--no-external-after-heuristic-failure
    Не выполнять повторный внешний проход.

--ocr
    Включить Tesseract OCR для проблемных/сканированных PDF.

--no-ocr
    Отключить OCR.

--pdf-first-pages N
    При включённом OCR читать и распознавать только первые N страниц каждого
    PDF. Значение 0 отключает ограничение и возвращает обработку всех страниц.

    Примеры:
        --ocr --pdf-first-pages 10
        --pdf-first-pages 0

--precount
    Перед обработкой быстро обойти каталоги и посчитать все подходящие файлы
    (включено по умолчанию). Общее число известно с первой строки прогресса и
    больше не меняется:

        [0/0]     Предварительный подсчёт файлов…
        [0/120]   Найдено файлов: 120. Начинаю обработку
        [1/120]   отчёт.docx

    Документы при подсчёте не открываются — обход опирается на os.scandir,
    поэтому стоит доли секунды даже на тысячах файлов.

--no-precount
    Начинать обработку немедленно, без подсчёта. Общее число уточняется по
    ходу поиска, поэтому знаменатель растёт, а доля выполнения скачет назад:

        [0/1]     Найдено файлов: 1
        [0/25]    Найдено файлов: 25
        [1/28]    отчёт.docx

    Имеет смысл на очень медленных сетевых дисках, где сам обход каталогов
    занимает заметное время и важнее начать читать документы сразу.

--workers NUMBER
    Число параллельных потоков обработки.

--timeout SECONDS
    Таймаут чтения одного файла. Допустимый безопасный диапазон настроек
    программы: 10–600 секунд.

--libreoffice FILE
    Путь к soffice.exe/soffice только для текущего запуска.

    Пример:
        --libreoffice "C:\Program Files\LibreOffice\program\soffice.exe"

--tesseract FILE
    Путь к tesseract.exe только для текущего запуска.

    Пример:
        --tesseract "D:\DSP\Tesseract-OCR\tesseract.exe"

Пути и лимиты CLI передаются дочерним процессам чтения через переменные
окружения и не перезаписывают пользовательский JSON.


9. ФОРМИРОВАНИЕ ЛОКАЛЬНОГО ОТЧЁТА
---------------------------------

--format xlsx
    Excel. Содержит листы "Результаты", "Сводка" и "Ошибки".

--format csv
    CSV с разделителем ";". При наличии ошибок дополнительно создаётся файл
    с суффиксом _errors.csv.

--format md
    Markdown-отчёт.

--output FILE_OR_DIR
    Полный путь файла или папка. Если расширение не соответствует формату,
    программа автоматически заменит его.

    Примеры:
        --format xlsx --output "D:\Reports\daily.xlsx"
        --format csv  --output "D:\Reports\"

Если --output не указан, отчёт создаётся в стандартной папке отчётов DSP Scanner.

--summary-json FILE
    Создать дополнительный краткий JSON для другой программы или скрипта.
    Он содержит: версию, статус, количество обработанных файлов, совпадений,
    ошибок, время, путь отчёта и факт отправки email.

    Пример:
        --summary-json "D:\Reports\daily_summary.json"

--fail-on-scan-errors
    Вернуть код завершения 6, если сканирование завершилось, но были ошибки или
    предупреждения чтения отдельных документов. Сам отчёт при этом создаётся.


10. ОТПРАВКА EMAIL
------------------

--send-email
    После сканирования сформировать вложение и отправить его по SMTP.
    Без этого флага CLI письмо не отправляет, даже если GUI-настройка
    "Автоматически отправлять" включена.

Формат вложения по умолчанию берётся из секции email в JSON.
Он может отличаться от формата локального отчёта.

--email-format {xlsx,csv,md}
    Переопределить формат вложения для текущего запуска.

--smtp-host HOST
    SMTP-сервер.

--smtp-port PORT
    SMTP-порт.

--smtp-security starttls
    STARTTLS, обычно порт 587.

--smtp-security ssl
    SSL/TLS с начала соединения, обычно порт 465.

--smtp-security none
    Соединение без шифрования. Используйте только в доверенной локальной сети.

--smtp-user USER
    Имя пользователя SMTP. Если не задано, SMTP AUTH не выполняется.

--mail-from ADDRESS
    Адрес отправителя. В поле должен быть ровно один email.

--mail-to ADDRESSES
    Основные получатели через запятую или точку с запятой.

--mail-cc ADDRESSES
    Получатели копии.

--mail-bcc ADDRESSES
    Получатели скрытой копии. Заголовок Bcc в письмо не добавляется.

--mail-subject TEXT
    Шаблон темы письма.

--mail-body TEXT
    Шаблон текста письма.

--smtp-timeout SECONDS
    Таймаут SMTP-соединения, 5–300 секунд.

--email-without-matches
    Отправлять письмо даже при нуле совпадений.

--no-email-without-matches
    Не отправлять письмо при нуле совпадений.

Доступные поля шаблонов темы и тела:

    {date}          дата и время окончания;
    {matches}       количество совпадений;
    {processed}     количество обработанных файлов;
    {errors}        количество записей ошибок/предупреждений;
    {elapsed}       длительность в секундах;
    {host}          имя компьютера;
    {status}        статус выполнения;
    {report_format} формат вложения.

ПАРОЛЬ SMTP
-----------
Передавать пароль ключом командной строки намеренно запрещено: аргументы могут
быть видны в истории команд и списке процессов.

Рекомендуемый серверный вариант:

    set DSP_SCANNER_SMTP_PASSWORD=очень_секретный_пароль

Для постоянной системной переменной Windows используйте защищённые средства
администрирования сервера или учётную запись службы.

Альтернатива: в GUI откройте:

    Настройки -> Почта и автоматическая отправка...

и включите "Сохранять пароль в переносимом JSON открытым текстом".
Это менее безопасно. Ограничьте права доступа к search_settings.json.


11. ВЫВОД В КОНСОЛЬ
-------------------

--quiet
    Не показывать текущий прогресс; итоговая строка и ошибки остаются.

--verbose
    Показывать подробный журнал, включая информационные сообщения ридеров.

Без специальных ключей отображается обычный прогресс вида:

    [12/150] Обработан: example.pdf

Для сохранения консольного вывода в Windows CMD:

    python main.py --cli ... >> "D:\Logs\dsp_scanner.log" 2>&1


12. КОДЫ ЗАВЕРШЕНИЯ
-------------------

0
    Сканирование и требуемые операции выполнены успешно.

2
    Ошибка аргументов или конфигурации.

3
    Не удалось создать локальный отчёт или summary JSON.

4
    Не удалось сформировать или отправить email.

5
    Непредвиденная внутренняя ошибка сканирования.

6
    Сканирование завершено, но найдены ошибки/предупреждения и был указан
    --fail-on-scan-errors.

130
    Операция отменена сигналом Ctrl+C/SIGTERM. KeyboardInterrupt не маскируется как внутренняя ошибка.


13. ПРИМЕРЫ
-----------

13.1. Использовать полностью готовую переносимую конфигурацию

    python main.py --cli

13.2. Сканировать одну папку и создать Excel

    python main.py --cli --no-config ^
      --path "D:\Documents" ^
      --types "docx,doc,txt,pdf" ^
      --content-terms "пилот; беспилотный аппарат; договор" ^
      --filename-terms "пилот; отчёт" ^
      --output "D:\Reports\scan.xlsx"

13.3. Поиск только по названиям файлов

    python main.py --cli --no-config ^
      --path "D:\Documents" ^
      --types "docx,doc,txt,pdf" ^
      --filename-term "пилот" ^
      --output "D:\Reports\names.xlsx"

13.4. Термины из двух текстовых файлов

    python main.py --cli --no-config ^
      --path "D:\Documents" ^
      --content-terms-file "D:\DSP\content_words.txt" ^
      --filename-terms-file "D:\DSP\filename_words.txt" ^
      --format csv ^
      --output "D:\Reports\"

13.5. Использовать JSON и заменить только путь и дату отчёта

    python main.py --cli ^
      --config "D:\DSP\server_scan.json" ^
      --path "D:\Documents" ^
      --output "D:\Reports\daily.xlsx"

13.6. Сканирование и отправка формата из настроек почты

    set DSP_SCANNER_SMTP_PASSWORD=секретный_пароль
    python main.py --cli ^
      --config "D:\DSP\server_scan.json" ^
      --send-email ^
      --output "D:\Reports\daily.xlsx" ^
      --summary-json "D:\Reports\daily_summary.json"

13.7. Отправить Markdown, оставив локальный отчёт Excel

    python main.py --cli ^
      --config "D:\DSP\server_scan.json" ^
      --format xlsx ^
      --output "D:\Reports\daily.xlsx" ^
      --send-email ^
      --email-format md

13.8. Запуск из Планировщика заданий Windows

Программа/скрипт:

    C:\Python312\python.exe

Аргументы:

    "D:\DSPScanner\main.py" --cli --config "D:\DSPScanner\DSPScanner_Config\search_settings.json" --send-email --quiet

Рабочая папка:

    D:\DSPScanner

Рекомендуется также настроить системную переменную DSP_SCANNER_SMTP_PASSWORD
для той учётной записи, от имени которой работает задание.

13.9. Возвращать ошибочный код при проблемных документах

    python main.py --cli ^
      --config "D:\DSP\server_scan.json" ^
      --fail-on-scan-errors ^
      --summary-json "D:\Reports\summary.json"

В этом случае отчёт всё равно будет создан, но ERRORLEVEL станет равен 6.
В bat-файле:

    if errorlevel 6 echo В сканировании были ошибки документов


14. ВАЖНЫЕ ЗАМЕЧАНИЯ
--------------------

* Файлы не удаляются и не перемещаются через CLI. CLI выполняет только чтение,
  поиск, экспорт и, при явном флаге, отправку email.
* Для OCR нужен рабочий Tesseract с языковыми файлами tessdata.
  Python-пакеты pytesseract и Pillow не требуются: бинарь запускается напрямую.
* Для точного чтения legacy .doc нужен LibreOffice либо MS Word COM.
* STARTTLS и SSL используют системную проверку сертификата.
* Пароль и содержимое документов не выводятся в консольный журнал.
* CSV-отчёт при наличии ошибок может отправляться двумя вложениями:
  основной CSV и файл *_errors.csv.
* Отчёты, автоматически отправленные из GUI, также сохраняются в стандартной
  папке отчётов DSP Scanner.


ДОПОЛНЕНИЕ ДЛЯ ВЕРСИИ 2.9.5 — ПУТИ ПО УМОЛЧАНИЮ
--------------------------------------------------

В переносимом JSON может храниться поле:

    "paths_mode": "default"

В этом режиме при каждом запуске список путей пересчитывается для текущего
компьютера:

1. профиль текущего пользователя (%USERPROFILE%);
2. все подключённые логические диски, кроме C:.

Это позволяет переносить конфигурацию на другой компьютер: имя пользователя и
набор дисков будут определены заново. В JSON также сохраняется вычисленный
список `paths` для наглядности, но источником истины остаётся `paths_mode`.

Если пользователь добавил или удалил путь вручную, GUI записывает:

    "paths_mode": "custom"

После этого CLI и GUI используют именно сохранённый список `paths`. Вернуться
к автоматическому режиму можно кнопкой «Выставить по умолчанию» в GUI.

Явный ключ `--path` всегда имеет наивысший приоритет и заменяет как
автоматические, так и пользовательские пути из JSON.

Если CLI запускается без JSON и без `--path`, он также использует системный
набор путей по умолчанию.
